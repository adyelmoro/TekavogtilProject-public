# Screenshots

Screenshots of the tekavogtil platform are added here after each milestone.

## How to capture (for the project owner)

1. Start the dev server: double-click `src/serve.bat`
2. Open `http://127.0.0.1:8000` in your browser
3. Take a full-page screenshot of each page listed below
4. Save as PNG at 1440px wide (or your full desktop width)
5. Place files in this folder with the exact filenames listed

---

## Required screenshots

| Filename | URL | Page |
|----------|-----|------|
| `homepage.png` | `/` | Full homepage — hero through footer |
| `services-browser.png` | `/tjenester` | Services browser — 6-card grid |
| `service-detail.png` | `/tjenester/web-mobilutvikling` | Any service detail page |
| `pricing.png` | `/priser` | Pricing page |
| `inquiry-form.png` | `/start` | Inquiry / start a project form |
| `contact-form.png` | `/kontakt` | Contact form |
| `admin-panel.png` | `/admin` | Filament admin panel dashboard |
| `language-toggle.png` | Any page | Close-up of the NO/EN language toggle in the nav |

---

## Recommended tools

- **Windows:** Snipping Tool (Win + Shift + S), or browser DevTools → Device Toolbar → capture full page
- **Full-page capture:** [GoFullPage](https://chrome.google.com/webstore/detail/gofullpage) Chrome extension
- **Crop / annotate:** [Greenshot](https://getgreenshot.org/) (free) or [CleanShot X](https://cleanshot.com/)

---

*Screenshots are not included in the repository while the platform is in private development.*
